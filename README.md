# fitnes

Журнал тренувань, ваги, кроків і звіти — PWA, яка встановлюється на телефон і працює офлайн.
Дані зберігаються лише на пристрої (IndexedDB); резервна копія — JSON у «Налаштуваннях».

App for fitness tracking and reports — an offline-first PWA, Ukrainian/English.

## Можливості

- **Запис дня** — ранкова вага, кроки, прогулянка й темп, інше кардіо, силова (8 базових вправ + свої,
  підказка «що було минулого разу»), біль 0–10 (стопа, спина, плече), тривожні ознаки з
  попередженнями, тиск і пульс, нотатка.
- **Огляд** — тиждень: середня ранкова вага й зміна, кроки, хвилини ходьби проти орієнтира фази,
  силові «X з N»; графік ваги за 8 тижнів із ковзним середнім за 7 днів; кроки за днями.
- **Історія** — усі записи, редагування й видалення.
- **Звіти** — тиждень або місяць: статистика, графіки, текстовий звіт (копіювати в чат / лікарю),
  експорт CSV, друк / PDF.
- **Налаштування** — мова (укр/англ), тема, фаза програми, дата старту, ціль кроків,
  резервна копія й імпорт JSON (приймає і формат попередньої сторінки «Журнал руху й ваги»).

## Розробка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit-тести (vitest)
npm run build    # збірка в dist/ з service worker
npm run preview  # перегляд збірки
```

Стек: React 19, TypeScript, Vite, vite-plugin-pwa, Dexie (IndexedDB). Графіки — власні SVG.

Структура:

- `src/lib/` — чиста логіка: типи, дати, статистика, конвертація форми, звіт, CSV, бекап (з тестами).
- `src/pages/` — екрани; `src/components/` — графіки, картки статистики, навігація.
- `src/i18n/` — словники `uk.ts` (джерело ключів) та `en.ts`.
- `src/db.ts` — схема IndexedDB і хуки `useDays` / `useSettings`.

`base: "./"` і HashRouter — збірку можна викласти на будь-який статичний хостинг (GitHub Pages тощо).
