# fitnes

Журнал тренувань, ваги, кроків і звіти — PWA, яка встановлюється на телефон і працює офлайн.
Дані зберігаються лише на пристрої (IndexedDB); резервна копія — JSON у «Налаштуваннях».

App for fitness tracking and reports — an offline-first PWA, Ukrainian/English.

## Можливості

- **Швидке внесення** — вага барабаном (як у будильнику), за замовчуванням з попереднього запису;
  кнопки −/+ з утриманням; біль і хвилини — дотиком; «Повторити минуле тренування».
- **Запис дня** — ранкова вага, кроки, прогулянка й темп, інше кардіо, силова (8 базових вправ + свої,
  підказка «що було минулого разу»), біль 0–10 (стопа, спина, плече), тривожні ознаки з
  попередженнями, тиск і пульс, нотатка.
- **Огляд** — тиждень: середня ранкова вага й зміна, кроки, хвилини ходьби проти орієнтира фази,
  силові «X з N»; графік ваги за 8 тижнів із ковзним середнім за 7 днів; кроки за днями.
- **Календар** — місяць у трьох режимах: активність (кроки, прогулянки, силові, тривожні ознаки),
  тиск (ранок/вечір, позначка від порога, середнє за місяць, швидкий запис заміру) і вага;
  дотик до дня показує все за цей день. Є й список усіх записів.
- **Обов'язкові відповіді** — вага (або «Не зважувався») і самопочуття («Усе гаразд» одним дотиком).
- **Звіти** — тиждень або місяць: статистика, графіки, текстовий звіт (копіювати в чат / лікарю),
  експорт CSV, друк / PDF.
- **Налаштування** — мова (укр/англ), тема, фаза програми, дата старту, ціль кроків,
  резервна копія й імпорт JSON (приймає і формат попередньої сторінки «Журнал руху й ваги»).

## Синхронізація без сервера

Дані пишуться на пристрій (IndexedDB) одразу, а коли є інтернет — зводяться з файлом
`fitnes-data.json` у твоєму **приватному** репозиторії GitHub через GitHub API
(при запуску, при поверненні зв'язку, після кожного збереження, раз на 5 хв).

- Злиття по днях: перемагає новіший запис (`updatedAt`); видалення синхронізуються як «надгробки».
- Налаштування: Settings → Developer settings → Fine-grained tokens → доступ лише до
  репозиторію з даними, Permissions → Contents: Read and write. Токен зберігається лише на пристрої.
- Кожна синхронізація — коміт, тож історія змін і резервна копія є автоматично.

## Кроки з Samsung Health

Вебзастосунок (PWA) не може читати Samsung Health: Samsung віддає кроки іншим застосункам лише через
**Health Connect** — API Android на пристрої, без вебдоступу; Google Fit API закривається наприкінці 2026.

- **Зараз:** імпорт експорту Samsung Health («Завантажити особисті дані») — можна вибрати одразу кілька
  файлів: `step_daily_trend` (кроки; сума телефон+годинник, `source_type = -2`), `exercise`
  (ходьба/похід/доріжка → хвилини прогулянки, решта → кардіо), `weight`, `blood_pressure`.
- **Вибір джерел:** у «Налаштуваннях» для кроків, ходьби й кардіо, ваги, тиску окремо —
  «Samsung Health» чи «вручну». Імпорт оновлює лише ввімкнені показники.
- **Коректний автоматичний шлях:** Android-оболонка (Capacitor) над цим самим застосунком +
  плагін Health Connect з агрегованим читанням `Steps` по днях (Health Connect сам прибирає дублікати
  між телефоном і годинником). Samsung Health → Health Connect синхронізується на телефоні.

## Розробка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit-тести (vitest)
npm run build    # збірка в dist/ з service worker
npm run preview  # перегляд збірки
```

Стек: React 19, TypeScript, Vite, vite-plugin-pwa, Dexie (IndexedDB). Графіки — власні SVG.

Структура:

- `src/lib/` — чиста логіка: типи, дати, статистика, конвертація форми, звіт, CSV, бекап (з тестами).
- `src/pages/` — екрани; `src/components/` — графіки, картки статистики, навігація.
- `src/i18n/` — словники `uk.ts` (джерело ключів) та `en.ts`.
- `src/db.ts` — схема IndexedDB і хуки `useDays` / `useSettings`.

`base: "./"` і HashRouter — збірку можна викласти на будь-який статичний хостинг (GitHub Pages тощо).

## Публікація

Кожен push у `main` збирає застосунок і викладає його на GitHub Pages
(`.github/workflows/deploy.yml`): <https://heresiarchus.github.io/fitnes/>.
Одноразово: Settings → Pages → Source: **GitHub Actions**.
